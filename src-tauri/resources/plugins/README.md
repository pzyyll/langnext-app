# Bundled runtime plugin packages

The committed official bundle contains vendor-signed `.lnplugin` archives and their exact
`default-activation-policies.json`. On every startup the app:

1. Imports each matching archive into the immutable plugin store (idempotent; already-installed
   digests are re-verified, never duplicated).
2. Projects every official package definition into the service catalog — including Baidu OCR
   with its `api-key` / `secret-key` credential slots — before any instance credentials exist.
3. Applies the exact vendor defaults idempotently: every official plugin is default-authorized
   with its activation policy on first startup and stays unchanged across restarts.

A present official bundle with a missing, empty, or incomplete policy file, or an official
archive that fails to import or project, is a startup readiness failure — never a silent
zero-default catalog. Missing user credentials are configuration state: credential-required
plugins (e.g. Baidu OCR) appear immediately and only become executable after the user supplies
credentials in the instance editor.

`default-activation-policies.json` entries generated by `mise run plugin:generate-bootstrap-policy`
are the only host-shipped default authorization source. Import alone never authorizes a default;
only exact policy entries can.

Required official archives:

- `com.langnext.google-translate-web-1.0.0.lnplugin`
- `com.langnext.edge-tts-1.0.0.lnplugin`
- `com.langnext.google-cloud-1.2.0.lnplugin`
- `com.langnext.provider.openai-compatible-1.0.0.lnplugin`
- `com.langnext.provider.openai-responses-1.0.0.lnplugin`
- `com.langnext.provider.anthropic-1.0.0.lnplugin`
- `com.langnext.provider.gemini-1.0.0.lnplugin`
- `com.langnext.provider.deepseek-1.0.0.lnplugin`
- `com.langnext.paddleocr-1.0.0.lnplugin`
- `com.langnext.baidu-ocr-1.0.0.lnplugin`

Validation:

```bash
mise run plugin:verify-release-bundle
```

The committed production resources must pass that command. Never hand-author digests or
authority ceilings; generate policy JSON from already signed archives. Never commit a private
signing key to this directory.
