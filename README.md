# Langnext

[中文](README.zh-CN.md)

Langnext is a desktop application for translation.

## Features

- **Models.** Connect a model provider.
- **Presets.** Save a translation setup. A preset can use AI Translation, the DeepL API, Google Cloud Translation, or Google Web, and it can keep prompt templates.
- **Google Web.** Translate without an API key through Google Translate's undocumented web endpoint. Google publishes no support, quota, or compatibility contract for it, so availability can change without notice.
- **Quick Translate.** Translate in a small window. The window remains available when the main window is hidden, and it can show several preset results for the same text.
- **Translate Selection.** Translate selected text on Windows.
- **Screenshot Translate.** Translate text in a screen region on Windows. Recognition can use a model, Baidu OCR, or Google Cloud Vision.
- **Double-copy.** Translate copied text after two quick copies on Windows.
- **Drag button.** Show a translate button after you drag over text.
- **Sentence alignment.** Match a translated sentence to its source sentence on Windows. Alignment runs on this computer.
- **History.** Open a recent translation again.
- **Text-to-speech.** Read a translation aloud through Google Cloud TTS or Azure Speech.
- **Back-translation.** Translate a result back toward the source language.
- **Wordbook.** Save one Quick Translate result to a local Anki deck.
- **Language detection.** Resolve an automatic language choice with a model, Google, or Google Cloud.
- **Appearance.** Use Light, Dark, or the system appearance.
- **Interface language.** Use the system language, English, or Simplified Chinese.
