# Langnext

[English](README.md)

Langnext 是一个用于翻译的桌面应用。

## 功能

- **模型。** 连接模型服务。
- **预设。** 保存一套翻译配置。预设可以使用 AI 翻译、DeepL API、DeepLX、Google Cloud 翻译或 Google 网页翻译，并可以保留提示词模板。
- **DeepLX。** 把翻译发送到你配置的 DLX 服务器。预设保存服务地址和可选的服务访问令牌。DeepLX 不是 DeepL API。
- **快速翻译。** 在小窗口中翻译。主窗口隐藏时窗口仍可使用，同一段文本可以同时显示多份预设译文。
- **划词翻译。** 在 Windows 上翻译选中的文本。
- **截图翻译。** 在 Windows 上翻译屏幕区域中的文字。识别可以使用多模态模型、百度 OCR 或 Google Cloud Vision。
- **双击 Ctrl+C 快速翻译。** 在 Windows 上翻译连续复制的文本。
- **拖选文本后显示翻译按钮。** 拖选文本后显示一个翻译按钮。
- **译文对照。** 在 Windows 上把译句对应到原句。对照在本机运行。
- **历史。** 再次打开最近的翻译。
- **语音合成。** 通过 Google Cloud TTS 或 Azure Speech 朗读译文。
- **回译。** 把译文译回源语言。
- **词典。** 在快速翻译中输入单个单词直接显示行内释义，或划选输入、译文、回译和历史文本通过浮标或快捷键 `Alt+D` 打开底部贴靠词典抽屉（`Alt+Left` 返回上一条，`Esc` 分层关闭）。在 **设置** 中配置词典通道。
- **生词本。** 把快速翻译结果或词典词条保存到本机的 Anki 牌组。
- **语言检测。** 用多模态模型、Google 或 Google Cloud 解析自动语言。
- **外观。** 使用浅色、深色或跟随系统。
- **界面语言。** 使用跟随系统、English 或简体中文。
