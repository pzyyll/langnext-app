# Langnext

[English](README.md)

Langnext 是一个用于翻译的桌面应用。你可以输入文本、翻译选中的文本，或翻译截图中的文字。一个快速翻译窗口可以同时显示同一段文本的多份译文。

## 准备翻译

1. 打开 **模型**，添加一个渠道。
2. 打开 **预设**，添加一个预设。预设可以使用 **AI 翻译**、**DeepL API** 或 **Google Cloud 翻译**。
3. 启用要使用的预设。

快速翻译只使用已启用的预设。

## 主窗口

- **设置 → 通用 → 语言** 将界面语言设为 **跟随系统**、**English** 或 **简体中文**。
- **设置 → 外观** 将外观设为 **浅色**、**深色** 或 **跟随系统**。关闭应用后，Langnext 会保留这个选择。

## 快速翻译

快速翻译是一个小窗口。主窗口隐藏时也可以打开它。

可以从系统托盘菜单中的 **快速翻译** 打开，也可以使用 Windows 快捷键。

| 操作 | 默认 | 结果 |
| --- | --- | --- |
| 打开快速翻译 | `Alt+Shift+D` | 打开或聚焦快速翻译。 |
| 截图翻译 | `Alt+S` | 选择一块屏幕区域。Langnext 识别其中的文字并翻译。 |
| 划词翻译 | `Alt+D` | Langnext 读取选中的文本并翻译。 |

在 **设置 → 应用 → 快捷键** 中更改快捷键：

1. 选择修改按钮，按下新的组合键。
2. 选择删除按钮，移除该快捷键。
3. 当前组合与默认值不同时，选择恢复按钮，恢复默认快捷键。

这些快捷键只在 Windows 上可用。如果 Langnext 启动时保存的快捷键不可用，Langnext 会发出警告。托盘菜单仍可打开快速翻译。如果新快捷键无法保存，之前的快捷键保持有效。

`Alt+D` 也会聚焦 Edge 或文件资源管理器的地址栏。如果 **打开快速翻译** 或 **截图翻译** 已经使用 `Alt+D`，该操作会保留这个按键。**划词翻译** 会保持未生效，直到你录制一个空闲的组合。选择恢复会再次尝试 `Alt+D`。如果该按键仍被占用，已保存的快捷键保持不变。

### 划词

**划词翻译** 会先用 Windows UI Automation 读取选区。它不使用 OCR。

**模拟复制获取文本** 默认关闭。当控件不提供选区时，在 **设置 → 应用 → 快捷键** 中打开它。Langnext 随后会尝试 `Ctrl+C`。这可能替换剪贴板中的内容。在 VS Code 中，如果没有选区，Langnext 不会翻译整行复制的内容。

以下结果在 Windows 上检查过：

| 应用 | 结果 |
| --- | --- |
| 记事本、Word 和 Chrome 搜索结果 | UI Automation 返回了选区。 |
| VS Code 1.146.0 | 打开 **模拟复制获取文本** 后，返回了编辑器中选中的文本。 |
| 一个 X 页面、Adobe Acrobat PDF 和 Windows Terminal | UI Automation 没有返回文本。 |

结果会随页面和应用版本变化。

密码框、没有选区，或 Langnext 无法读取的控件，仍会打开快速翻译并保留当前草稿。没有选区时会显示未选中文本。无法读取选区时，提示中可以开始 **截图翻译**。取消区域选择后，草稿保持不变。

### 拖选按钮

**拖选文本后显示翻译按钮** 默认关闭。在 **设置 → 应用 → 快捷键** 中打开它。拖选文本后，指针旁边会出现 **划词翻译** 按钮。点击之前，按钮不会读取任何内容。点击只使用 UI Automation，不会发送 `Ctrl+C`。

按钮会在三秒后隐藏，也会在按钮外的下一次按下、使用该按钮或打开快速翻译时隐藏。**划词翻译** 快捷键仍然可用。

### 双击复制

**双击 Ctrl+C 快速翻译** 默认关闭。这个快捷键是固定的。在 **设置 → 应用 → 快捷键** 中打开或关闭它。连续按两次 `Ctrl+C` 会打开快速翻译，并用已启用的预设翻译复制的文本。

### 卡片和语言

这些卡片共用一段原文和一对语言。每张卡片使用一个预设和一个提示词模板。

- 拖动卡片标题栏可以调整顺序。也可以聚焦拖动手柄，然后按上方向键或下方向键。
- 选择标题栏上控件以外的区域，可以折叠或展开卡片。
- Langnext 会保存卡片顺序。

在标题栏的语言菜单中设置源语言和目标语言。**自动** 会使用语言检测。参见 [语言检测](#语言检测)。

**自动翻译** 默认关闭。打开后，你停止修改文本 500 ms，Langnext 才会翻译。窗口显示出复制的文本时就会翻译，即使 **自动翻译** 是关闭的。按 Enter 翻译。按 `Shift+Enter` 换行。

在译文卡片上可以复制文本、以 Markdown 或纯文本显示、朗读，以及请求回译。朗读需要在 **设置 → 集成 → 语音合成** 中添加渠道。

### 截图中的文字

**截图翻译** 只在 Windows 上可用。截取区域之前，先在 **设置 → 集成 → OCR** 中配置 OCR。可以添加 **多模态模型**、**百度 OCR** 或 **Google Cloud Vision**。已启用的渠道按从上到下的顺序使用。后面的渠道作为备用。

选择一块屏幕区域。Langnext 识别文字，并用已启用的预设翻译。也可以从托盘菜单开始这个操作。

### 译文对照

译文对照只在 Windows 上可用。它把译句对应到原句。对照在本机运行，不会把文本发给其他服务。翻译请求仍会把全文发给所选的服务。

1. 打开 **设置 → 应用 → 快捷翻译**。
2. 下载 **Multilingual E5 Small**（约 135 MB），或打开 **译文对照**。如果还没有模型，Langnext 会要求确认下载，并等到文件校验完成且模型加载完成。
3. 在模型这一行选择 **取消**，可以停止下载。**译文对照** 保持关闭时，也可以选择 **下载**。

对照已打开且原文已展开时，指向一句译文即可看到对应的原句。也可以聚焦译文，按左方向键或右方向键在已匹配的句子之间移动。

纯文本和 Markdown 正文都可以对照。复制出去的文本不会改变，非正文的 Markdown 块会被跳过。编辑文本、更改选区、滚动、折叠卡片或隐藏窗口时，高亮会清除。

关闭 **译文对照** 会清除当前高亮。已安装的模型会保留。Langnext 不会更改译文，也不会再次发送文本。

### 历史

Langnext 保留最近 30 次翻译的原文和成功的译文。打开 **历史** 可以恢复已保存的结果。恢复不会重新请求翻译。数据库留在本机，而且不会加密。

历史不保存草稿、错误或按键。

## 生词本

生词本把一条快速翻译结果保存到本机的 Anki 牌组。保存目标并打开之前，它保持关闭。Langnext 不会自行打开生词本。

1. 在 Anki Desktop 中安装 AnkiConnect 插件。插件代码是 `2055492159`。
2. 保持 Anki Desktop 打开，并打开一个用户配置和一个普通牌组。
3. 打开 **设置 → 集成 → 生词本**。
4. 只有 AnkiConnect 要求密钥时才填写。保存的 API 密钥留在本机，而且不会加密。
5. 选择 **测试连接**。选择牌组、笔记类型和译文字段。笔记类型的第一个字段是来源字段。
6. 选择 **保存**，然后打开 **启用 Anki**。

Langnext 只向 `http://127.0.0.1:8765` 发送 Anki 请求。正向翻译完成后，选择 **加入 Anki**。该操作发送这张卡片的原文和译文。它不发送历史、回译或其他卡片。如果该原文已经存在于所选牌组和笔记类型中，Anki 不会修改它。

Langnext 不声明支持某一个 Anki 版本、某一个 AnkiConnect 版本或某一个桌面平台。

## 语言检测

语言检测会在翻译前把 **自动** 解析为具体语言。已启用的检测器按从上到下的顺序运行。后面的检测器作为备用。本机没有检测器。

1. 打开 **设置 → 集成 → 语言检测**。
2. 选择 **添加渠道**。
3. 添加 **多模态模型** 并选择一个模型，或添加 **Google**，或添加 **Google Cloud** 并保存 API Key。**Google** 不需要密钥，添加后即启用。
4. 设置 **母语** 和 **目标语言**。

添加并启用检测器之前，检测保持关闭。

- **多模态模型** 把一段样本发给一个文本模型。无法使用的回答会交给下一个已启用的检测器。
- **Google** 使用免费的 Google 翻译接口。
- **Google Cloud** 用你的 API Key 调用 Cloud Translation，并由该项目计费。密钥栏留空时，会保留已保存的密钥。

拖动检测器的手柄可以调整顺序，也可以聚焦手柄后按上方向键或下方向键。第一个已启用的检测器是首选。

目标语言为 **自动** 时，其他语言会译成母语，母语会译成 **目标语言**。源语言和目标语言都已指定时，不会开始检测。

没有已启用的检测器时，**自动** 源语言需要你选择源语言。**自动** 目标语言需要设置母语。

对同一段输入，快速翻译只检测一次 **自动** 源语言。朗读原文时，如果检测尚未运行，会使用同一次检测。之后对这段输入的翻译会复用该结果，包括展开卡片和重试。编辑输入，或更改检测器顺序，会重新检测。失败的检测不会被复用。

检测被阻止或失败时，不会猜测语言。卡片或朗读错误会要求你选择源语言。取消检测时不会提示。

每个实际运行的检测器都会收到修剪后文本的前 2,048 个字符。该服务可以与翻译预设不同。完整原文仍会发给翻译服务。Langnext 不保存也不记录样本、检测到的语言或模型回复。

## 日志

打开 **设置 → 通用 → 日志**，选择 **打开文件夹**。

在 Windows 上，日志文件是 `%APPDATA%\com.dev.langnext\logs\app.log`。文件达到 5 MiB 时滚动。Langnext 保留三个旧文件，从 `app.1.log` 到 `app.3.log`。

**设置 → 通用 → 日志等级** 设置 Langnext 写入的最低等级：**错误**、**警告** 或 **信息**。默认是 **警告**。该设置不包括 `debug` 行。

## 隐私

- 服务密钥留在本机。
- 翻译会把原文发给已启用预设卡片所对应的服务。
- 只有翻译或朗读需要自动确定源语言时，语言检测才会发送文本，并且对同一段输入只发送一次。
- 译文对照留在本机。
- Langnext 不记录原文、译文或 API 密钥。
